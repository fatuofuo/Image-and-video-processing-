# Image and video Technology Lab Projects

This repository contains two lab assignments.

## Repository Contents

*  **Project 1: Image and video processing** 
  * **Description:** Implementation of foundational computer vision techniques, including Gaussian and Laplacian pyramids for multi-scale image analysis, video processing, and feature extraction.

* **Project 2: Deep Learning Architectures for Image Classification** 
  * **Description:** Design, training, and evaluation of foundational Convolutional Neural Networks (CNNs) including LeNet, AlexNet, and VGGNet, exploring structural differences and feature representation capabilities.

## Tools 
* **Language:** Python
* **Environment:** Jupyter Notebook
